# ⚡ 寶可夢 TCG 抽卡機

單檔 HTML 寶可夢卡牌抽卡遊戲（繁中），直接用瀏覽器開啟即可遊玩。

## 玩法

- **橫掃開包** — 喺卡包上向左橫掃，模擬撕開卡包
- **每包 5 張卡** — 稀有度機率遞增，第 5 張最稀有
- **1025 隻寶可夢** — 齊集全國圖鑑（關都至帕底亞，9 代全收錄）
- **5 級稀有度** — 普通 / 罕見 / 稀有 / 超稀有 + 閃光（4%）
- **3D 翻轉** — 點擊卡片翻面睇 HP、招式、類型
- **點擊大圖** — 圖鑑點擊卡片彈出大圖，睇清卡面細節
- **收藏圖鑑** — 自動儲存收藏進度（localStorage），可按稀有度/世代/屬性篩選 + 名稱搜尋
- **合成音效** — 橫掃、開包、翻卡、稀有卡慶祝（Web Audio，無需外部檔案）
- **PWA 離線** — 可安裝到主螢幕，Service Worker 離線快取
- **成就系統** — 13 個成就 + 統計頁 + 資料匯出/匯入備份

## 資料來源

- 卡圖：寶可夢官方繁中卡圖（`asia.pokemon-card.com`）
- 卡牌資料：[type-null/PTCG-database](https://github.com/type-null/PTCG-database)（data_tc）
- 每隻寶可夢由該資料庫選取一張代表性卡（優先 ex/V/VMAX/GX 特別版）

## 技術

- 純前端單檔（HTML + CSS + JS），零依賴、零後端
- 圖片直連官方 CDN，可離線遊玩（除卡圖外）
- 支援手機觸控 + 桌面滑鼠

## 部署

```bash
# 任何靜態伺服器即可
python3 -m http.server 8080
# 或直接雙擊 index.html 用瀏覽器開啟
```
